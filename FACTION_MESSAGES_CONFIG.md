# Настройка интервалов сообщений фракций

## Конфигурация

Интервалы сообщений фракций теперь настраиваются в файле `src/config/game-config.json` в секции `factionMessages.intervals`.

**ВАЖНО:** Интервалы указаны в **игровых часах**, а не в реальном времени!

### Время в игре:
- 1 игровой день = 5 минут реального времени (3 мин день + 2 мин ночь)
- 1 игровой час = ~12.5 секунд реального времени
- 24 игровых часа = 1 игровой день

### Текущие настройки:

```json
"factionMessages": {
  "intervals": {
    "hq": {
      "hours": 2.0,
      "description": "Штаб - каждые 2 игровых часа"
    },
    "rebels": {
      "hours": 4.0,
      "description": "Повстанцы - каждые 4 игровых часа"
    },
    "free": {
      "hours": 2.0,
      "description": "Свободные - каждые 2 игровых часа"
    },
    "mystery": {
      "hours": 6.0,
      "description": "Тайна - каждые 6 игровых часов"
    },
    "marauders": {
      "hours": 3.0,
      "description": "Мародеры - каждые 3 игровых часа"
    }
  },
  "enabled": true,
  "description": "Настройки интервалов генерации сообщений фракций (в игровых часах). 1 игровой день = 5 минут реального времени (3 мин день + 2 мин ночь)"
}
```

## Как изменить интервалы

### 1. Редактирование конфига
Откройте файл `src/config/game-config.json` и измените значение `hours` для нужной фракции:

```json
"hq": {
  "hours": 1.0,  // Каждые 1 игровой час (~12.5 сек реального времени)
  "description": "Штаб - каждые 1 игровой час"
}
```

### 2. Через консоль браузера (в реальном времени)

```javascript
// Просмотреть текущие интервалы
updateFactionMessageIntervals()

// Изменить интервал для конкретной фракции
setFactionMessageInterval('hq', 1.0)  // 1 игровой час
setFactionMessageInterval('rebels', 2.0)  // 2 игровых часа
setFactionMessageInterval('free', 1.0)  // 1 игровой час
setFactionMessageInterval('mystery', 3.0)  // 3 игровых часа
setFactionMessageInterval('marauders', 2.0)  // 2 игровых часа
```

## Значения интервалов (в игровых часах)

- `0.5` = 30 игровых минут (~6 сек реального времени)
- `1.0` = 1 игровой час (~12.5 сек реального времени)
- `2.0` = 2 игровых часа (~25 сек реального времени)
- `4.0` = 4 игровых часа (~50 сек реального времени)
- `6.0` = 6 игровых часов (~75 сек реального времени)
- `12.0` = 12 игровых часов (~2.5 мин реального времени)
- `24.0` = 1 игровой день (~5 мин реального времени)


## Примечания

- **Интервалы указаны в игровых часах, а не в реальном времени!**
- Изменения в конфиге применяются при перезагрузке игры
- Изменения через консоль применяются немедленно
- Система использует внутриигровое время (`this.time.now`) для всех расчетов
- Если конфиг не загружен, используются fallback значения
- 1 игровой день = 5 минут реального времени (3 мин день + 2 мин ночь)
