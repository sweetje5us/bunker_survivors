🔧 Инструкции по балансировке

Как изменить баланс игры:

  1. Откройте файл: src/config/game-config.json
  2. Найдите нужный параметр в соответствующем разделе
  3. Измените значение на желаемое
  4. Сохраните файл
  5. Перезапустите игру для применения изменений

Примеры изменений:

  • Опыт за врагов: Измените значения в "enemyKillRewards"
  • Начальные ресурсы: Измените значения в "initialResources"
  • Урон врагов: Измените значения в "enemyDamage"
  • Потребление ресурсов: Измените значения в "resourceConsumption"
