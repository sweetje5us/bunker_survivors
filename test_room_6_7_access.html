ПРОБЛЕМЫ ОБНАРУЖЕНЫ

🚫 Проблема 1: Застревание при переходе 5 → 6

Симптом: Жители застревают при попытке выйти из комнаты 5 в комнату 6.
Последствие: Комнаты 6 и 7 становятся недоступными для достижения жителями.
КРИТИЧЕСКАЯ ПРОБЛЕМА

📡 Проблема 2: Телепортация из дальних комнат

Симптом: Если переместить жителя в комнату 7 с помощью drag & drop, он телепортируется в другую комнату в следующий игровой час.
Причина: Система считает жителей в дальних комнатах "застрявшими".
КРИТИЧЕСКАЯ ПРОБЛЕМА

🔧 Найденные и исправленные причины

🎯 Причина 1: Принудительная релокация "застрявших" жителей

Проблема: Функция checkStuckAgents считала жителей в дальних комнатах "застрявшими" и принудительно перемещала их.
Решение: Добавлена проверка, которая предотвращает принудительное перемещение жителей, находящихся в любой комнате.
// ИСПРАВЛЕНИЕ: Предотвращение принудительной релокации // ВАЖНАЯ ПРОВЕРКА: Если агент находится в комнате (любой), он НЕ считается застрявшим // Это предотвращает принудительное перемещение жителей из дальних комнат const isInAnyRoom = currentRoomIndex !== null const shouldNotRelocate = isInAnyRoom && !wasRecentlyDragged if (((isStuck && hasNoTarget && !wasRecentlyDragged) || isStuckInTransition) && !shouldNotRelocate) { // Только теперь считаем агента застрявшим }
ИСПРАВЛЕНО

🛣️ Причина 2: Проблемы с построением пути к дальним комнатам

Проблема: Система построения пути не могла правильно создать маршруты к комнатам после 5-й.
Решение: Добавлены отладочные сообщения и улучшена логика buildHorizontalChain.
// ИСПРАВЛЕНИЕ: Улучшенная система построения пути const buildHorizontalChain = (fromIdx: number, toIdx: number): number[] | null => { // Находим все комнаты на том же этаже const roomsOnSameFloor = [] for (let i = 0; i < this.roomRects.length; i++) { if (Math.abs(this.roomRects[i].y - sameY) < 1e-3) { roomsOnSameFloor.push(i) } } // Сортируем комнаты по X координате roomsOnSameFloor.sort((a, b) => this.roomRects[a].x - this.roomRects[b].x) // Создаем путь через все комнаты между fromIdx и toIdx const path: number[] = [] const start = Math.min(fromPos, toPos) const end = Math.max(fromPos, toPos) for (let i = start; i <= end; i++) { path.push(roomsOnSameFloor[i]) } return path }

🔍 Добавлена отладочная информация

Улучшение: Добавлены подробные консольные сообщения для отслеживания построения путей.
console.log(`[buildPathTo] Построен горизонтальный путь от комнаты ${curIndex} к комнате ${destIndex}, длина цепи: ${chain.length}`) console.log(`[buildHorizontalChain] Комнаты на этаже ${sameY}: ${roomsOnSameFloor.join(', ')}`) console.log(`[buildHorizontalChain] Построен путь: ${path.join(' -> ')}`)

🎯 Корневая причина

Проблема была не в ограничении количества комнат, а в том, что система считала жителей в дальних комнатах "застрявшими" и принудительно перемещала их. Это создавало иллюзию недоступности комнат 6-7.
