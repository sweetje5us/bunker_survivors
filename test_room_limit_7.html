🐛 Исходная проблема

📊 Проблема с дальними комнатами

Симптом: Жители не могут дойти до дальних комнат справа (после 5-й комнаты).
Дополнительная проблема: При размещении жителей в дальние комнаты через drag & drop они "ломаются" и стоят на месте.

🔧 Принятое решение

🎯 Ограничение на 7 комнат в ряду

Решение: Вместо попыток исправить систему передвижения для дальних комнат, мы ограничиваем постройку максимум 7 комнатами в ряду.
Обоснование: Это предотвращает создание проблемных дальних комнат, которые жители не могут достичь.

⚙️ Техническая реализация

🔧 Восстановлена функция canAddRoomToRow

Функция: Проверяет, можно ли добавить комнату на указанный этаж, не превышая лимит.
/** * Проверяет, можно ли добавить комнату на указанный этаж, не превышая лимит */ private canAddRoomToRow(y: number, maxRoomsPerRow: number): boolean { const tolerance = 5 // Допуск для определения этажа // Считаем количество комнат на этом этаже let roomsOnThisRow = 0 // Считаем обычные комнаты for (let i = 0; i < this.roomRects.length; i++) { const room = this.roomRects[i] if (Math.abs(room.y - y) <= tolerance) { roomsOnThisRow++ } } // Считаем основной лифт if (Math.abs(this.elevatorRect.y - y) <= tolerance) { roomsOnThisRow++ } // Считаем дополнительные лифты for (const lift of this.extraElevators) { if (Math.abs(lift.y - y) <= tolerance) { roomsOnThisRow++ } } console.log(`[canAddRoomToRow] Этаж Y=${y}: ${roomsOnThisRow} комнат, лимит: ${maxRoomsPerRow}`) return roomsOnThisRow < maxRoomsPerRow }

// ОГРАНИЧЕНИЕ: Максимум 7 комнат в ряду (включая лифт) const maxRoomsPerRow = 7 for (let i = 0; i < this.roomRects.length; i++) { const room = this.roomRects[i] const rightPos = { x: room.x + room.width + gap, y: room.y, roomWidth: newRoomWidth, roomHeight: newRoomHeight } // Проверяем, не превысит ли добавление комнаты лимит в 7 комнат на этаже if (this.isPositionValid(rightPos) && this.canAddRoomToRow(rightPos.y, maxRoomsPerRow)) { positions.push(rightPos) } }

🧪 Рекомендации по тестированию

📋 Сценарии для проверки

  1. Тест лимита: Попробуйте построить 8-ю комнату в ряду - система не должна предлагать позиции
  2. Тест доступных позиций: При попытке добавить комнату должны показываться только позиции в пределах лимита
  3. Тест передвижения: Жители должны свободно перемещаться между всеми 7 комнатами в ряду
  4. Тест drag & drop: Жители, размещенные в любую из 7 комнат, должны работать корректно
  5. Тест консоли: В консоли должны появляться сообщения о подсчете комнат на этаже
К ВЫПОЛНЕНИЮ

🔍 Что искать в консоли

При попытке добавить комнату должны появляться сообщения:
[canAddRoomToRow] Этаж Y=0: 6 комнат, лимит: 7 [canAddRoomToRow] Этаж Y=0: 7 комнат, лимит: 7
Когда лимит достигнут (7 комнат), новые позиции не будут предлагаться.

🎯 Логика ограничения

Подсчет комнат: Система считает все комнаты на одном этаже (включая лифты) и не позволяет превысить лимит в 7 комнат.
Допуск: Используется допуск в 5 пикселей для определения принадлежности к одному этажу.
Лимит: Максимум 7 комнат в ряду (включая лифт и вход).
